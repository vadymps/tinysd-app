About

TinySD UI

TinySD UI is a web app for orchestrating image generation via third-party APIs with automated Cloudinary storage and display.

Generate

Turn text prompts into visuals quickly with a focused workflow that keeps generation simple and fast.

Organize

Save, review, and manage your favorite images in the gallery so your best results are always close by.

Stack

Built with Angular, Angular Material, and Tailwind-style utility classes, with a lightweight API powering generation and storage.

Need help? Start with the Image Generator tab, then browse the Gallery to review your saved images.
